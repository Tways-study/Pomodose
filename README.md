# Pomodose

A pharmacist-themed Pomodoro timer, daily goal tracker, and AI chat companion. Work sessions are "Doses," breaks are "Refills" and "Antidotes," and Dosey — your study companion — is on hand to talk through your progress.

Everything lives on a single page (`app/page.tsx`); there's no routing beyond authentication and the chat API.

## Features

- **Timer** — a timestamp-driven Pomodoro timer (`lib/timer-machine.ts`) visualized as a liquid-filled vial, with a Flask / Graduated Cylinder vessel toggle (`components/vial-timer.tsx`).
- **Goals** — a daily goal list backed by Convex, rolling over at local midnight.
- **Dosey** — an AI chat companion (`components/dosey-chat.tsx`) powered by Gemini, aware of your live timer and goal state.
- **Auth** — password-only email/password sign-in via Convex Auth. No email verification or password reset, so no external mail provider is required.

## Getting Started

### Prerequisites

- A [Convex](https://www.convex.dev) deployment (`npx convex dev` to set one up)
- A [Gemini API key](https://ai.google.dev/) for Dosey

### Environment variables

Create `.env.local` with:

```bash
CONVEX_DEPLOYMENT=
NEXT_PUBLIC_CONVEX_URL=
NEXT_PUBLIC_CONVEX_SITE_URL=
GEMINI_API_KEY=
```

`CONVEX_DEPLOYMENT` / `NEXT_PUBLIC_CONVEX_URL` / `NEXT_PUBLIC_CONVEX_SITE_URL` are generated by `npx convex dev`.

Convex Auth needs its signing keys (`JWT_PRIVATE_KEY`, `JWKS`) and `SITE_URL` set directly on the Convex deployment (these are per-deployment, not read from `.env.local`). Generate the keys with:

```bash
npx @convex-dev/auth        # sets JWT_PRIVATE_KEY + JWKS on the deployment
npx convex env set SITE_URL "http://localhost:3000"   # your app's origin
```

> **Deploying to production:** env vars are per-deployment, so repeat the auth-key
> and `SITE_URL` setup against the prod deployment (`npx @convex-dev/auth --prod`,
> and `SITE_URL` = your deployed URL), then push functions with `npx convex deploy`.

### Run the app

```bash
npm install
npx convex dev      # in one terminal, keeps Convex functions in sync
npm run dev          # in another terminal
```

Open [http://localhost:3000](http://localhost:3000).

## Commands

```bash
npm run dev         # start dev server (localhost:3000)
npm run build        # production build
npm run lint         # eslint (flat config, eslint-config-next)
npm run typecheck    # tsc --noEmit
npm test             # vitest run (single run, used in CI)
npm run test:watch   # vitest watch mode
```

Run a single test file: `npx vitest run lib/dosey.test.ts`

CI (`.github/workflows/ci.yml`) runs lint → typecheck → test → build in that order on every push/PR to `main`.
